คุณสามารถบันทึกหน้านี้เป็นไฟล์ HTML เพียงไฟล์เดียว แล้วอัปโหลดขึ้น GitHub Pages เพื่อแชร์ให้ทีมงานหรือสาธารณะใช้งานได้ฟรี 24 ชม.!

  1. ดาวน์โหลดโค้ด: บันทึกไฟล์นี้เป็นชื่อ index.html
  2. สร้าง Repository: ไปที่ GitHub.com → สร้าง Repository ใหม่ (ตั้งเป็น Public)
  3. อัปโหลดไฟล์: กด Upload files → ลากไฟล์ index.html เข้าไป → กด Commit
  4. เปิดใช้งาน Pages: ไปที่ Settings → Pages → เลือก Branch main แล้วกด Save
